NETCOMMAND LAB (GNS3)  -  paste each block into the matching device.
Topology: CORE connects to SW1, SW2 and R1.  SW3 connects to SW2 only.
A Cloud node (bound to your laptop adapter) connects to CORE.  Laptop = 192.168.1.10/24.

Management IPs: R1 192.168.1.1, CORE .2, SW1 .3, SW2 .4, SW3 .5
Login used by the app: admin / YOUR_LAB_PASSWORD   (lab only!)

======================= COMMON BASE (every SWITCH) =======================
(change the hostname and the vlan 1 address on each device)

enable
configure terminal
hostname CORE
no ip domain-lookup
ip domain-name lab.local
username admin privilege 15 secret YOUR_LAB_PASSWORD
crypto key generate rsa modulus 2048
ip ssh version 2
line vty 0 4
 login local
 transport input ssh
exit
interface vlan 1
 ip address 192.168.1.2 255.255.255.0
 no shutdown
end
write memory

======================= ROUTER R1 =======================
(the IP goes on the physical interface, not vlan 1)

hostname R1
no ip domain-lookup
ip domain-name lab.local
username admin privilege 15 secret YOUR_LAB_PASSWORD
crypto key generate rsa modulus 2048
ip ssh version 2
line vty 0 4
 login local
 transport input ssh
exit
interface GigabitEthernet0/0
 ip address 192.168.1.1 255.255.255.0
 no shutdown
end
write memory

======================= PLANTED MISTAKES =======================
Leave "service password-encryption" OFF on every switch (it is off by default).

SW2: allow Telnet  ->  finding telnet_enabled (high)
  configure terminal
  line vty 0 4
   transport input all
  end

SW1: one access port WITHOUT port security  ->  finding no_port_security
  configure terminal
  interface FastEthernet0/1
   switchport mode access
   switchport access vlan 10
  end
  (do NOT add "switchport port-security" to it; if the image has no Fa ports use Gi0/3)

SW1: one trunk WITHOUT an allowed-VLAN list  ->  finding trunk_all_vlans
  configure terminal
  interface GigabitEthernet0/1
   switchport trunk encapsulation dot1q
   switchport mode trunk
  end
  (do NOT add "switchport trunk allowed vlan ...")

SW3: single link to SW2  ->  SW2 is a single point of failure (articulation point)
  (this comes from the cabling, nothing to type)

======================= CHECKS BEFORE TESTING =======================

From the laptop:  ping 192.168.1.2   then   ssh admin@192.168.1.2
